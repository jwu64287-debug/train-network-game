# 华夏轨道模拟运营游戏

在线版本：<https://jwu64287-debug.github.io/train-network-game/>

这是基于 CorelDRAW 矢量铁路图制作的纯静态铁路网络模拟运营游戏。运行文件位于 `dist`，GitHub Pages 会自动发布 `main` 分支中的 `dist` 目录。

当前版本接入新版矢量线网：主要站与非主要站按原图的两种圆圈尺寸及约 3 PT／2 PT 注记识别；细虚线作为轮渡区间，运行速度统一为 40 km/h。已建线路可上移、下移或直接调整位次。进入画面的铁路主题图片是生成示意图，不是实地摄影，也不用于计算站点坐标。

地图坐标沿用原始矢量图的统一比例换算，没有单独拉伸横轴或纵轴。线网初始视窗与“复位”会完整包含兰州以西至新疆的新增线路。原图若存在地理位置误差，仍需以可靠的地理控制点进一步校准。浏览器存档保存在本机，上线后请先备份重要存档再逐一检查。

更换电脑、恢复存档或继续开发前，请完整阅读 [新电脑迁移与继续开发说明](MIGRATION_GUIDE_CN.md)。
